( updated on 15-June-2026 )

New Features & Enhancements:
1. Double-Sidebar Navigation & Menu Search
   - Added a brand-new double-sidebar navigation system featuring a collapsible rail and context panels, allowing users to jump between major categories and workspaces effortlessly.
   - Added a new "Quick Access" panel to sidebar menus to jump directly to Tasks, Projects, Todos (with unread badges), Notes, and Chat.
   - Added a keyboard shortcut (press "/" key) to focus the sidebar menu search instantly, with highlighted search queries for faster navigation.
2. Complete UI Overhaul (V2 Design System)
   - Redesigned user interfaces across all modules—including Projects, Tasks, Clients, Users, Leads, Candidates, Contracts, Payslips, Expenses, Allowances, Deductions, Payments, Taxes, Units, Items, and Notes—for a clean, modern look.
   - Replaced old data tables with clean, spacious, responsive tables that support saving your column display preferences.
   - Redesigned forms and popup windows (modals and slide-out panels) with clean spacing, aligned buttons, and user-friendly file upload boxes featuring live image previews.
   - Fully optimized the dashboard layout, including birthday, work anniversary, and leave filters to ensure they line up perfectly on desktop and mobile screens.
   - Resolved the dark mode loading issue where pages briefly flashed white before loading the dark theme.
3. Smoother Selection & Filter Experience
   - Replaced slow dropdown selection fields across the entire application with modern, lightweight select boxes, resolving layout clipping in popup windows and slide-out panels.
   - Upgraded search filters across all modules so they update results instantly without requiring manual page refreshes.
   - Standardized input fields with consistent hover and focus border transitions to feel more responsive.
4. Better Kanban Boards & Drag-and-Drop
   - Improved drag-and-drop behavior on Kanban boards (Leads, Candidates, Tasks, Projects, and Todos) so you can only drag actual cards—preventing column headers, buttons, and section dividers from being moved by mistake.
   - Fixed status updates when dragging cards, making sure your columns update instantly and securely without any errors.
   - Styled Todo progress bars, priority badges, and drag handles to adjust automatically between light and dark modes.
5. Smart Theme Color Customization
   - Brand color settings are now synchronized instantly: updating your company primary color updates all buttons, tags, calendar cells, and highlights across both light and dark modes without glitches.
   - Redesigned Settings pages (SMS, Company Details, Security, PWA, Email) into clean, modern layouts that display perfectly in both light and dark modes.
6. Module Enhancements (Assets & Social Media Scheduler)
   - Restructured Asset Management category tables and form panels into a clean, single-column layout.
   - Standardized the Social Media Scheduler list view and platform filters, bundling action buttons inside clean three-dot dropdowns.

Additional Improvements:
- General visual improvements to inputs (hover/focus borders), badges, and navigation menus.
- Under-the-hood performance optimizations for faster page loading and smoother transitions.
